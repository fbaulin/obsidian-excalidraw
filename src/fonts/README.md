The JSON contains the original font bytes as a data URI
and their SHA-256 digest. No font download is required at build or runtime.

Source: https://raw.githubusercontent.com/mathjax/MathJax/2.7.9/fonts/HTML-CSS/TeX/otf/MathJax_Math-Italic.otf

Picker name: LaTeX Math Italic. Persistent scene font ID: 10001.
Existing LaTeX Text Italic elements now use variable-style italic without rewriting
their source text or IDs. Their geometry may reflow due to different metrics.
This face is for mathematical letters; unsupported characters use engine fallbacks.
It does not parse TeX or interpret subscripts, and does not change MathJax.
The engine's font registry supplies canvas loading and SVG font embedding.
The user-configured Local Font and existing built-in IDs are not replaced.
