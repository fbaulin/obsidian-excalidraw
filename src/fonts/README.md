# LaTeX Text Italic

Unmodified Latin Modern Roman 10 Italic (`lmroman10-italic.otf`), by Bogusław
Jackowski and Janusz M. Nowacki. Distributed under the GUST Font License;
see GUST-FONT-LICENSE.txt. The JSON contains the original font bytes as a data URI
and their SHA-256 digest. No font download is required at build or runtime.

Source: https://ctan.math.illinois.edu/fonts/lm/fonts/opentype/public/lm/lmroman10-italic.otf

Picker name: LaTeX Text Italic. Persistent scene font ID: 10001.
This is text italic, not mathematical-variable italic. It does not change MathJax.
The engine's font registry supplies canvas loading and SVG font embedding.
The user-configured Local Font and existing built-in IDs are not replaced.
